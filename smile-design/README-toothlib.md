# Tooth library

Parametric crown meshes (FDI 11-16 in four wear variants) generated with the DentCraft anatomy library
(https://github.com/elnajar1/DentCraft, MIT / Apache-2.0, Dr Mahmoud ElNajar), decimated and quantised to 0.005 mm.
Frame: +X mesial, +Y facial, +Z occlusal. Each entry holds base64 int16 vertices (v), uint16 faces (f) and the cervical loop (c).
